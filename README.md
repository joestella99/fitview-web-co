# FitView Web Co.

The company website for **FitView Web Co.**, a small web design studio focused on websites for running, strength and fitness coaches.

## Website

- **Starter (Essentials):** starting at **$300** for a one-page coaching website.
- **Growth:** starting at **$500** for up to four pages.
- **Website refresh:** custom quote.
- Clients own their domains and hosting accounts; FitView does not host their websites.
- Contact: jastella18@gmail.com

## Run locally

This is a static HTML website with inline CSS and no build dependencies.

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy to Vercel

Connect this GitHub repository to the existing Vercel project `fitview-web-co` in **Project Settings → Git**, then select `main` as the production branch. The project should use **Other / No Framework Preset** and the repository root as its Root Directory.

The business storefront should be hosted using a plan that permits commercial use; Vercel Hobby is intended for non-commercial projects.

The separate coaching demo is not part of this repository.
